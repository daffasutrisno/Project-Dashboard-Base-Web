## 📊 Cara Menampilkan Data Historical

Untuk menampilkan data actual/historical di chart forecast, jalankan script ekstraksi:

```bash
# Navigate to forecast_programs folder
cd forecast_programs

# Run the extraction script
python extract_historical_data.py
```

Script ini akan:

1. Membaca data dari `Traffic_VLR_Java_2024-2025.xlsx`
2. Mengekstrak data historical per regional/provinsi/kabupaten
3. Menyimpan ke `public/forecast_data/[type]/[name]_historical.csv`

Setelah script dijalankan, refresh halaman dan chart akan otomatis menampilkan:

- **Data Actual** (dari historical data) dengan warna solid
- **Garis pembatas hijau** dengan label "Forecast Start"
- **Data Forecast** (dari forecast data) dengan lower & upper bounds

## 🎨 Chart Features

### MonthlyIndexChart

- Bar chart dengan rata-rata per bulan
- Format: "Month Year" (Jan 2025, Feb 2025, dst)
- Warna: #465fff (biru primary)

### ForecastChart

- Area chart dengan 3 series:
  - **Total Traffic**: Gabungan historical + forecast
  - **Lower Bound**: Batas bawah forecast (ditampilkan jika ada data forecast)
  - **Upper Bound**: Batas atas forecast (ditampilkan jika ada data forecast)
- Annotation: Garis vertikal hijau di awal forecast dengan label "Forecast Start"
- Smooth transitions antara historical dan forecast
